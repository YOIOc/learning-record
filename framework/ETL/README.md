## ETL概念

ETL（Extract, Transform, Load）是数据仓库和数据集成的核心过程：

- **Extract（提取）**: 从源系统中提取数据
- **Transform（转换）**: 对提取的数据进行清洗、转换和整合
- **Load（加载）**: 将转换后的数据加载到目标系统
